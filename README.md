# CIAN-Editor · ویرایشگر چیدمان «پرونده در یک پوست‌گردو»

صفحه‌ی ویرایشگر چیدمان اتاق‌های بازی Case in a Nutshell. نشانی نهایی:

```
https://luckylion.games/case-in-a-nutshell/editor/
```

وضعیت: فاز ۱ (نمایشگر): اتاق و لحظه را عوض می‌کنید، شبکه و جای پای اشیا، شماره‌ها، اقلام کوچک و هشدارهای چیدمان را می‌بینید و یک تصویر مرجع نیمه‌شفاف زیر اتاق می‌گذارید. جابه‌جایی و ذخیره در فاز ۳ می‌آید.

## این مخزن چیست

دو فایل ایستا و بدون مرحله‌ی ساخت:

```
index.html   صفحه
editor.js    منطق صفحه
```

خودِ موتور و پرونده‌ها را این مخزن ندارد. صفحه موقع اجرا از پوشه‌ی `../assets/` بازی می‌خواند:

```
../assets/editor-manifest.json   فهرست پرونده‌ها و هش اسکریپت‌ها (بیلد مخزن بازی می‌سازد)
../assets/engine.js              موتور (شامل src/engine/layout.js)
../assets/case-<slug>.js         پرونده‌ی انتخاب‌شده، همراه layout.json خودش
```

پس صفحه باید کنار بازی سرو شود: `.../case-in-a-nutshell/editor/index.html` و `.../case-in-a-nutshell/assets/`.
مخزن بازی: `eqbalhozhabr/Case-in-a-Nutshell` (کد موتور، فایل‌های `layout.json` و ابزارهای صدور آنجاست).

## اجرا و آزمون

```bash
npm run assemble        # بازی را می‌سازد و بازی + ویرایشگر را در out/site/ کنار هم می‌گذارد
npm run serve           # همان را روی http://localhost:8080/editor/ می‌گذارد
npm test                # آزمون مرورگری (نیاز به playwright)
```

مخزن بازی به‌طور پیش‌فرض در `../Case-in-a-Nutshell` جست‌وجو می‌شود؛ مسیر دیگر را با `GAME_DIR` بدهید.

## گذاشتن روی سایت

بعد از `npm run assemble`، پوشه‌ی `out/site/` همان چیزی است که زیر `public/case-in-a-nutshell/` در مخزن سایت قرار می‌گیرد (بازی و `editor/`). فقط فایل اضافه می‌شود.
دسترسی ویرایشگر هنوز محدود نیست (فقط خواندنی است و چیزی را نشان نمی‌دهد که بسته‌های بازی نشان نمی‌دهند)؛ ورود با دعوت‌نامه در فاز ۴ می‌آید.

## مسیر کار

1. نمایشگر، شبکه، جای پا، هشدارها (انجام شد)
2. کتابخانه‌ی اسپرایت
3. ویرایش: جابه‌جایی، چرخش، حذف، افزودن، لغو و بازگشت، ذخیره‌ی `layout.json`
4. آنلاین: بازی چیدمان منتشرشده را موقع بارگذاری از یک نشانی JSON می‌گیرد؛ ورود با دعوت‌نامه، پیش‌نویس و انتشار
5. بارگذاری تصویر
